# Baby Steps Android

A standalone Android application and home-screen widget inspired by the 8-bit retro Tamagotchi pregnancy tracker from Omalauncher.

## Features
- **Standalone Android App**: Fullscreen WebView with custom pixel art canvas engine running at smooth 60fps.
- **Home Screen Widget**: Native Android AppWidget (`AppWidgetProvider`) with live gestational week, baby fruit comparison, and due date progress countdown.
- **Customizable**: Baby name, gender (Girl 🎀 / Boy 🧢 / Surprise 💛), day/night sleep cycle simulation, and interactive music groove reaction.
- **GitHub Actions CI/CD**: Automatically builds and uploads `BabySteps-Android-Debug-APK` on every push to `main`.
